360км

Подключение за 5 минут

  1. 1Токен Wialon
  2. 2Машины в приложении
  3. 3Первая сверка

Заправки подтягиваются выгрузкой с АЗС или вносятся руками с чеком.

  • Нужна ли телематика?

    Да. Пробег Поток берёт из телематики, без него нечего сверять с заправками. Токен вставляется один раз, машины появляются сами.

  • Работает без Wialon?

    Сейчас поддерживается Wialon. Заправки можно вносить руками или загружать выгрузкой с АЗС, но пробег для сверки нужен из телематики. Другие системы подключим по запросу первых парков.

  • Данные в безопасности?

    Данные каждой компании изолированы: один парк не видит другой. Соединение шифруется, доступ по ролям: водитель видит только свою машину и свою заправку.

  • Сколько машин?

    От 10 до 150. Меньше держится в голове, больше требует других процессов. Проверено на полутора сотнях машин.

  • Есть ли iOS?

    Пока нет. Сейчас приложение для Android, версия для iOS позже. Отчёты и документы бухгалтеру выгружаются из того же приложения.
